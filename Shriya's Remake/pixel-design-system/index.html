schema 3-Tier Token Architecture & Hierarchy

How PIXEL decouples raw visual primitives from contextual semantic meaning, enabling multi-theme switching without modifying component markup.

1. Primitive Token --pixel-primitive-blue-800: #1E40AF
Raw mathematical hex value representing the unopinionated brand cobalt hue.
2. Semantic Token --pixel-action-primary: var(--pixel-primitive-blue-800)
Contextual role representing the primary clickable action. In Dark Mode, dynamically remaps to #2563EB.
3. Component Token Binding .pixel-btn--primary { background: var(--pixel-action-primary); }
Components consume semantic tokens exclusively, ensuring zero hardcoded hex codes across the UI.
