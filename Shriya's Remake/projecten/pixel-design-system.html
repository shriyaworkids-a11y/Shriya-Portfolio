01 / Project Overview

Why I Created PIXEL

When designing multiple screens for digital products, inconsistencies quickly creep in—mismatched button sizes, duplicate hex codes, and arbitrary spacing. I created PIXEL to practice building an organized, scalable UI library in Figma, ensuring design decisions are modular, reusable, and predictable.

01 · Reusable Master Components Built flexible components in Figma with Auto Layout and variant properties so changing a primary style propagates across all screens instantly.
02 · Predictable Component States Defined default, hover, active, focus, and disabled states across interactive controls so developers and users never experience ambiguous interactions.
03 · 8px Spatial Rhythm Standardized all padding, gaps, and component margins to an 8px grid (4px, 8px, 16px, 24px, 32px) to eliminate guesswork and maintain visual balance.

03 / Component Library

Core UI Components & Variants

Every component was built in Figma using Auto Layout and property variants before being translated into clean HTML and CSS tokens.

As a UI designer, creating a design system taught me that consistent components are about more than just matching colors. Each component needs predictable sizing, clear states, and responsive resizing rules so other designers and developers can use them effortlessly.

In PIXEL, I focused on standardizing the most frequently used interface elements:

FIGMA COMPONENT SPEC

Button / Primary / Medium (40px)

Height: 40px fixed
Padding: 10px 16px (Auto Layout)
Corner Radius: 6px (radius.md)
Typography: Inter 14px / 600 Semibold
States: Default, Hover, Active, Focus, Disabled, Loading
Layout: Hug contents with 8px icon spacing
Component 01

Buttons & State Variants

Primary, secondary, outline, and ghost variations. Each variant includes full state definitions — hover transitions, active press scaling, high-contrast focus rings, and layout-preserving loading spinners.

Component 02

Form Inputs & Controls

Standardized 40px height text fields, search bars, and dropdown menus with clear top-aligned labels, subtle helper text, and high-visibility focus borders.

Component 03

Status Badges & Tags

Compact status pills with semantic color fills (Success Green, Info Blue, Warning Amber, Neutral Slate) to quickly communicate system statuses in dense layouts.

Component 04

Cards & Data Displays

Modular card containers with consistent 16px/24px padding, subtle border separation, and clear typographic hierarchy for dashboards and content previews.

04 / Reflections

What Building a Design System Taught Me

Key takeaways and skills I developed while structuring this system from scratch.

Figma Mastery

Auto Layout & Reusable Components

Building components with Auto Layout and nested variants drastically reduced the time needed to design new screens, while ensuring layouts adapt gracefully to different screen sizes.

Clarity

Defining Explicit States

Interfaces shouldn't leave interaction states up to guesswork. Designing clear default, hover, focus, disabled, and loading states ensures front-end developers can implement designs accurately.

Design Consistency

The Power of Consistent Spacing

Using a strict 8px spacing scale eliminated random margins and padding across my designs, making every screen feel naturally balanced and polished.
