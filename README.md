# Shriya's Portfolio

Welcome to the official repository for **Shriya's Portfolio Website** — showcasing UI/UX design, product videography, branding, web development, and digital marketing works.

## 🌟 Featured Sections
- **Hero & Profile**: Introduction, creative background, and interactive visual presentation.
- **Projects & Works**:
  - UI / UX & App Designs
  - Product Videography & Commercial Reels
  - Social Media & Graphic Design
  - Websites & Brand Identity
- **About**: Story, skills, tools, and design philosophy.
- **Contact**: Inquiries and collaboration details.

## 📂 Project Structure
- `Shriya's Remake/` — Main portfolio website (HTML, CSS, JavaScript, media assets).
- `Breems Original/` — Reference templates and design prototypes.
- `Google Drive Work/` — Portfolio media library and export assets.

## 🚀 Local Development
Simply open `Shriya's Remake/index.html` in any modern web browser or serve with a local static server.
